# Revisão de licença

A metadata da versão local revisada declara MIT. Os quatro arquivos originais não contêm cabeçalhos de terceiros, avisos GPL ou indicação de código copiado. Não foi importado histórico Git.

O widget usa APIs do KDE/Qt e executa Codex CLI; não incorpora os binários dessas dependências. As dependências mantêm suas próprias licenças. PySide6 é uma dependência de execução separada, com licenças LGPL/GPL/comercial; não é redistribuído neste projeto.

A declaração MIT existente permite preparar a mesma licença para o código do widget. A autoria e a ausência de trechos copiados não podem ser comprovadas apenas por inspeção: o mantenedor deve confirmar a procedência antes da publicação. Qualquer código de terceiros adicionado deve conservar seus avisos e licença.

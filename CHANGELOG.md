# Alterações

## 1.1.0 — 2026-10-07

- Versão Windows 11 com indicador `5H …% | 7D …%` sobre a barra de tarefas, fora dos ícones de sistema.
- Atualização a cada 15 segundos após concluir a consulta e atualização manual.
- Login ChatGPT pelo navegador, perfil exclusivo e armazenamento no cofre de credenciais do Codex.
- Segoe UI Variable com ClearType, três tamanhos de fonte, nove cores e cor personalizada; preferências locais persistentes.
- Painel com limites, renovação, uso de tokens e remoção das credenciais do widget.
- Instalador por usuário, pasta privada com ACL, verificação de possíveis segredos e pacote com lista explícita de arquivos públicos.
- A versão KDE permanece disponível; o indicador Windows não reserva espaço nativo no Explorer.
